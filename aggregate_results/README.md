# Aggregate results

These files contain non-identifiable aggregate outputs used in the revised manuscript. They contain no SEER patient-level records. Each file is regenerated by the analysis scripts from the restricted SEER input held outside version control.

- `spline_sensitivity_model_fit.csv`: alternative age-function specifications.
- `complete_case_model_fit.csv`: complete-case interaction tests.
- `eod_histology8160_tests.csv`: histology-8160-only three-category EOD sensitivity analysis.
- `cancer_rmtl_differences.csv`: five-year cancer-death restricted mean time lost by age group, including 1000 patient-cluster bootstrap confidence intervals.
